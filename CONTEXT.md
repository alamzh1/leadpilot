# LeadPilot

Концепт B2B-сервиса, который превращает название компании в профиль для первого контакта, и лендинг с интерактивным демо на вымышленных данных.

## Язык

**Рабочая область**:
Интерфейс исследования: поисковая строка, рельс этапов, карточка профиля, источники и блок решения. Анимированная копия живёт в hero, рабочая версия в демо.
_Не путать_: дашборд, иллюстрация, скриншот.

**Демо-компания**:
Одна из трёх вымышленных компаний (Northstar Bank, Vector Logistics, Atlas Commerce), единственные, которые демо умеет исследовать.
_Не путать_: клиент, кейс, реальная компания.

**Демо-профиль** («Demo profile»):
Итоговая карточка демо-компании со статусом «Demo profile». Данные в ней вымышлены и не считаются фактами.
_Не путать_: отчёт, досье, результат реального поиска.

**Полнота профиля (демо)**:
Доля заполненных полей карточки, например «9 из 10 полей». Статус «Demo profile» не считается.
_Не путать_: качество, точность, AI-оценка, рейтинг.

**Повод для первого контакта**:
Блок решения в карточке: причина написать компании и должность, кому писать. Только должность, без имён и контактов.
_Не путать_: лид-скоринг, рекомендация по продаже.

**Verified**:
Состояние поля в карточке: данные подтверждены, цвет лайм. Голубой означает непроверенный фрагмент.
_Не путать_: гарантия точности, подтверждённый факт о реальной компании.

**Этап исследования**:
Один из четырёх шагов прогона: «Анализ компании», «Поиск IT-инициатив», «Определение релевантных должностей», «Формирование профиля». Около 0,7 с каждый.
_Не путать_: шаг процесса «Как работает» (Discover, Verify, Qualify).

**Живой анализ**:
Реальное исследование произвольной компании. Есть только в полной версии, в демо вместо него уведомление.
_Не путать_: ручной ввод (он лишь выбирает демо-компанию).

**Хром окна**:
Служебная обвязка рабочей области: строка пути, блочный курсор, префикс `leadpilot /`. Не считается текстом страницы.
_Не путать_: eyebrow, кикер, подпись над заголовком.

**Пиксельная сборка**:
Фирменная анимация: голубые 4px-фрагменты ступенчато сходятся в поле карточки. При reduced-motion не рисуется.
_Не путать_: загрузочный спиннер, частицы.

**Фолбэк**:
CSS-замена изображения (сетка или градиент из палитры), которая показывается, пока файла нет или он не загрузился.
_Не путать_: плейсхолдер, заглушка.
